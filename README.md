# Duplicate Order Checker — EcomModa

![version](https://img.shields.io/badge/version-v1.0.0-blue)

أداة داخلية من ستاك EcomModa بتتكوّن من قطعتين:

| القطعة | الملف | بتعمل إيه |
|---|---|---|
| **Worker** | `index.js` | بيستقبل ويبهوك `orders/create` من شوبيفاي، وبيدوّر على أوردر تاني غير منفَّذ بنفس رقم تليفون الشحن في آخر ٩٠ يوم. لو لقى، بيضيف تاج `Duplicate` وسطر في نوت الأوردر. |
| **الواجهة** | `index.html` | صفحة واحدة على GitHub Pages بتعرض **سجل الفحص** — عرض فقط، بلا أي فعل. |

## 👁️ الواجهة عرض فقط

مفيش في الصفحة أي زرار بيعدّل أوردر، ولا بيشغّل الفحص يدويًا، ولا بيمسح صف من السجل.
كل الـ endpoints اللي بتناديها الصفحة قراءة (`get_logs*` · `get_log_types` · `get_config` · `diag`)
أو تحقق دخول (`check_employee` · `verify_employee` · `register_pin`).

## اللي فيها

- شاشة دخول بالـ PIN من جدول الموظفين المشترك (خطوتين: اختيار الاسم ← الـ PIN).
- جدول السجل: التاريخ · الوقت · نوع العملية · رقم الأوردر · الأوردرات المكررة · صفحات مفحوصة · الموظف · الملاحظات.
- فلاتر **كلها server-side**: نوع العملية والموظف (اختيار متعدد) · فترة سريعة + من/إلى تاريخ · بحث برقم الأوردر أو الملاحظات.
- ترتيب على الأعمدة (server-side، ٣ حالات) · صفحات ١٠٠ صف · تصدير XLSX بتحذير صريح لو الملف اتقص.
- زرار 🩺 فحص ذاتي في الإعدادات — بيعرض أسماء وأطوال الأسرار، **مش قيمها**.

## التشغيل

1. افتح الواجهة: `https://ecommoda-dev.github.io/Duplicate-Order-Checker/`
2. ⚙️ الإعدادات → الزق `WORKER SECRET` → حفظ.
3. اختار اسمك وادخل الـ PIN.

الرابط بتاع الـ Worker مكتوب في الكود مباشرةً — مش حقل إعدادات ومش سر.

## النشر

- **الـ Worker**: Cloudflare Workers Builds من الريبو ده (`index.js` + `wrangler.toml`).
- **الواجهة**: GitHub Pages من `main` / `/ (root)`.

> 🔴 قبل ربط الريبو بـ Workers Builds — لازم تتنسخ قيمة `DUPLICATE_NOTE_PREFIX`
> من داشبورد كلاودفلير جوّه `wrangler.toml`. التفاصيل والسبب مكتوبين في الملف نفسه.

باقي التفاصيل التشغيلية (الـ endpoints · قيم D1 · الفخاخ · بصمة المهارات) → `CLAUDE.md`.
